# SprintBoard  Agile project management for modern teams - Sprint planning, task boards, team collaboration.  ## Features  - Sprint planning & tracking - Kanban/Scrum boards - Task management with drag-and-drop - Team collaboration - Project analytics & burndown charts - Calendar & timeline views  ## Tech Stack  - React 19 - Redux Toolkit - React Router v7 - Tailwind CSS v4 - Vite 7 - Recharts for analytics  ## Getting Started  ```bash npm install npm run dev ```  ## Scripts  - `npm run dev` - Start development server - `npm run build` - Build for production - `npm run preview` - Preview production build - `npm run lint` - Run ESLint
